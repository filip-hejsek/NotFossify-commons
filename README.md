# NotFossify Commons

A personal fork of [Fossify Commons](https://github.com/FossifyOrg/Commons), stripped down to what
[Filip's Music Player](https://github.com/filip-hejsek/music-player) needs. It is not affiliated
with or endorsed by Fossify, and it is not meant for use by other apps.

The Maven coordinates (`org.fossify:commons`) and package names are kept from upstream so that it
can replace the upstream library without code changes.
